# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within AgentGuard, please send an email directly to **Ray Bayly** at:
`security@bayly.ai` or `ray@bayly.ai`.

We will acknowledge receipt within 48 hours and coordinate fixes and disclosures.
