# Changelog

All notable changes to the "agentguard-vscode" extension will be documented in this file.

## [1.0.0] - 2026-10-04

### Initial Release
- **Quad-Graph Activity Bar Explorer:** Interactive navigation across Agents, Roles, Invariants, Rules, Memory, and Code AST hierarchy.
- **RBAC Security Gate Inspector:** Real-time pre-execution authorization evaluation for multi-agent tool execution.
- **FinOps Token Telemetry:** Live system prompt overhead tracking, token reduction metrics, and distribution analytics.
- **Topological DAG Validation:** Substrate health monitoring with cycle detection and dangling edge alerts.
- **Interactive Visual Canvas:** Embedded Mermaid.js diagram viewer with zoom, pan, and priority level filtering.
- **Zero-Prompt-Tax Synthesizer:** Command palette action to generate deterministic, token-efficient system prompts.
