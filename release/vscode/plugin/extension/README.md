> **Enterprise AI Agent Governance, Quad-Graph Cognitive Substrate, Deterministic RBAC Security Gates, and FinOps Token Analytics inside Visual Studio Code.**

---

## 🚀 Key Features

- 🛡️ **Quad-Graph Navigation:** Browse Agents, Roles, Invariants, Rules, Memory, and Code AST directly in the Activity Bar.
- 🔒 **RBAC Security Gate Inspector:** Check deterministic tool execution permissions and security boundaries per role.
- 💰 **FinOps Token Telemetry:** Monitor token reduction (95% token tax savings) and prompt overhead in real time.
- 🎨 **Visual Architecture Webview:** Interactive Mermaid graph canvas with zoom, pan, and priority filters.
- 🔍 **Deterministic System Prompt Synthesizer:** Generate lean, zero-prompt-tax system prompts tailored to active roles.
- ⚡ **Auto-Sync:** Keeps governance substrate automatically synchronized upon saving code, directives, or configuration files.

---

## 🛠️ Installation

```bash
# Install local release package
code --install-extension release/vscode/plugin/agentguard-vscode-1.0.0.vsix
```

---

## ⚙️ Extension Settings

- `agentguard.executablePath`: Path to the standalone `agentguard` binary or Python interpreter.
- `agentguard.autoSyncOnSave`: Automatically sync Quad-Graph substrate on file save (default: `true`).
